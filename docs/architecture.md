# Arquitectura Sprint 1

- Monolito modular con apps independientes (`api`, `web`) dentro de un monorepo.
- Multi-tenant y multi-sucursal desde el modelo de datos.
- Autorización resuelta en backend mediante JWT + rol.
- Frontend mobile-first con guards por rol.
- Preparado para despliegue en GCP (Cloud Run para apps, Cloud SQL PostgreSQL).
